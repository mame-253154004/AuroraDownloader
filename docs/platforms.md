# Platform notes (Windows / Android / iOS)

## Windows
- Desktop runner ve native lib yükleme adımları platform entegrasyonunda tamamlanacak.

## Android
- Uzun indirmeler için foreground service gerekir.
- Bildirim ve yaşam döngüsü kısıtları dikkate alınmalıdır.

## iOS
- Arka plan indirmeleri için URLSession background download gerekir.
- App Store politikalarını bypass etmeye yönelik bir yaklaşım uygulanmayacaktır.
