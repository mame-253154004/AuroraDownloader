# Security Policy

## Scope
AuroraDownloader is local-first and serverless in this bootstrap.

## Security principles
- No telemetry by default.
- Do not log sensitive tokens/cookies/credentials.
- Reject unsafe URL targets by policy (private/loopback/link-local/etc.).
- Never add DRM bypass, CAPTCHA bypass, cookie theft, or unauthorized access features.

## Reporting a vulnerability
Please open a private security report through GitHub Security Advisories.
